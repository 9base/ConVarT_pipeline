# 9base ConVarT pipeline preservation

**Status: Preserved.** Documentation reconstructed from repository history on 8 October 2026.

This is an upstream-derived reference copy of [thekaplanlab/ConVarT_pipeline](https://github.com/thekaplanlab/ConVarT_pipeline), retained alongside related ConVarT work. The analysis pipeline, scientific design and inherited README are Kaplan Lab work. Before documentation curation, `hash-search`, `master` (default) and `pipeline-update` were identical to their same-named upstream branches. No fork-specific technical development was established by the audit.

The inherited overview describes conserved clinical/nonclinical amino-acid variants, alignments, protein domains and post-translational modifications. Its historical database counts are preserved as upstream documentation, not refreshed measurements. Current execution or deployment was not verified.
